## Reference data provisioning (DEVELOPMENT dataset)

The upstream engine's reference database is normally **derived from external datasets** and is
not redistributed (the resources repo ships empty `raw/` placeholders). For the dev cluster we
provision a **small, reproducible DEVELOPMENT reference dataset** (not the production corpus):

- Generated by `tools/address-data/generate_dev_reference.py` (pinned, deterministic).
- It contains the model + `misc/` (from the resources repo) plus a reduced
  towns/country/postcode corpus for Italy, India, Saudi Arabia, UK, Germany, France, Spain,
  Netherlands.
- **This is NOT the production GeoNames/restCountries corpus.** It is used only to prove the
  real provider path end-to-end in the dev cluster.
- **Production reference data** must be generated from the external datasets below and mounted
  at `/resources` (replacing the dev dataset). It is governed by its own licenses.

### External datasets (for production reference data)

- **GeoNames** (towns/alternate names/postcodes): **CC BY 4.0** (attribution required).
  Source: `download.geonames.org/export/...`.
- **restCountries**: **MPL 2.0**.
- **Wikipedia-derived reference data**: **CC BY-SA 4.0** (share-alike).
- **Training data**: **ODbL v1.0** share-alike (resources LICENSE §§4.4–4.8).

These datasets are **not redistributed** in this repository; the dev dataset is synthetic and
self-contained (no external downloads). The production reference data must be generated and
mounted at deploy time, under the above licenses.

## Bundled ISO 20022 subset schema

`schemas/iso20022/pacs.008.001.08/*.xsd` is a CloudNova-authored subset. The official ISO 20022
schemas are the property of ISO and are substituted under a proper ISO license in production.
